# Inventory Management System

## Modules

### OCR

- **Description**: A fully implemented Invoice Processing & Product Matching system with Gemini AI integration, hybrid product matching, Supabase database support, and Streamlit dashboard UI.

- **Folder Structure**:
  ```
  ├── ocr/
  │   ├── api/                   # OCR API endpoints
  │   ├── Streamlit/              # Streamlit user interface
  │   ├── Models/                 # Machine learning models
  │   ├── Scripts/                # Script to run the OCR processing
  │   ├── resultsOfModel/         # Results generated from the model
  │   ├── requirements.txt        # Dependencies for the OCR module
  │   └── __init__.py             # Package initialization
  ```
